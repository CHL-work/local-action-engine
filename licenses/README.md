# Unity package license notices

These files preserve the original license and third-party notice texts from the resolved Unity packages. Package names and versions match `unity/Packages/packages-lock.json`. They are copied without changing their bytes; `index.json` records origin, source-relative filename, SHA-256 and size.

The collection includes the resolved dependency closure, including build/test-only packages. It does not claim that every listed component is linked into the Player. Built-in engine modules without separate package notice files are governed by Unity's applicable runtime terms.

The original repository license does not replace these component terms. The Windows runtime allowlist includes this complete notice collection.
